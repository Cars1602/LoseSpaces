# LoseSpaces

## Presentacion final

Ejecutable: `Builds/LostInSpace/LostInSpace.exe`. Distribuir toda la carpeta a cada jugador.
La escena inicial es `Assets/Scenes/MenuPrincipal.unity`. Incluye video introductorio, menu con modelos 3D animados, musica, tripulacion/equipo, registros, ajustes y carga de la expedicion. Instalar las cinco piezas activa el despegue y la pantalla de victoria.
